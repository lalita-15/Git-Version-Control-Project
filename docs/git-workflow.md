
# Git Workflow

## Repository Initialization
Create a local repository using `git init` command.

## Branch Management
Use `main`, `dev`, and feature branches to organize development.

## Commit Management
Save changes with meaningful commit messages.

## Pull Requests
Review and merge feature changes into `dev`, then merge `dev` into `main`.

## Version Tagging
Create an annotated tag such as `v1.0.0` to identify a release.

## Verification
Use Git commands to verify branches, commit history, and tags.

## Feature Development
New changes are developed in feature branches and reviewed through pull requests
